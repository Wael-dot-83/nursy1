## Getting Started

### First Time Login

1. **Access the System**
   - Open your web browser
   - Navigate to the system URL (e.g., https://nursery.yourdomain.com)
   - You should see the login page

2. **Login**
   - Enter your email address
   - Enter your temporary password (provided by your administrator)
   - Click "Login"

3. **Change Your Password**
   - On first login, you'll be prompted to change your password
   - Enter your current password
   - Create a new strong password:
     - At least 8 characters
     - Include uppercase and lowercase letters
     - Include at least one number
     - Include at least one special character
   - Confirm your new password
   - Click "Update Password"

### Navigation

The system uses a sidebar navigation menu on the left side:
- **Dashboard**: Your main overview page
- **Menu items**: Specific to your role
- **Profile**: Access your account settings
- **Logout**: Sign out of the system

## Admin Guide

Administrators have full access to all system features and settings.

### Dashboard Overview

The admin dashboard displays:
- Total number of nurseries
- Total registered users
- System statistics
- Recent activities
- System health status

### Managing Nurseries

#### Create a New Nursery

1. Click "Nurseries" in the sidebar
2. Click "Add New Nursery" button
3. Fill in the nursery details:
   - **Name**: Official nursery name
   - **Address**: Physical location
   - **Phone**: Contact number
   - **Email**: Nursery email address
   - **Capacity**: Maximum number of children
4. Click "Create Nursery"

#### Edit Nursery Information

1. Navigate to "Nurseries"
2. Find the nursery in the list
3. Click the "Edit" button
4. Update the necessary fields
5. Click "Save Changes"

#### Deactivate/Delete Nursery

1. Go to "Nurseries"
2. Find the nursery
3. Click the three-dot menu
4. Select "Deactivate" or "Delete"
5. Confirm the action

### User Management

#### Create New User

1. Click "Users" in the sidebar
2. Click "Add New User"
3. Fill in user details:
   - **Email**: User's email address
   - **First Name** and **Last Name**
   - **Phone Number**
   - **Role**: Select from:
     - Admin: Full system access
     - Manager: Nursery management
     - Parent: View their children only
     - Supervisor: Daily operations
   - **Nursery**: Assign to a nursery (if applicable)
   - **Temporary Password**: Create initial password
4. Click "Create User"

The user will receive their login credentials via email.

#### Manage User Roles

1. Navigate to "Users"
2. Filter by role if needed
3. Click on a user to view details
4. Click "Edit" to modify:
   - Role assignment
   - Nursery assignment
   - Active status
5. Click "Save Changes"

#### Reset User Password

1. Go to "Users"
2. Find the user
3. Click the three-dot menu
4. Select "Reset Password"
5. Generate a new temporary password
6. The user will be notified to change it on next login

### System Reports

#### View Attendance Reports

1. Click "Reports" in sidebar
2. Select "Attendance Report"
3. Choose filters:
   - Date range
   - Nursery
   - Specific children (optional)
4. Click "Generate Report"
5. Export as CSV or PDF if needed

#### Financial Reports

1. Go to "Reports"
2. Select "Financial Report"
3. Choose:
   - Nursery
   - Date range
   - Report type
4. Click "Generate"

### Audit Logs

View all system activities:
1. Click "Audit Logs" in sidebar
2. Filter by:
   - User
   - Action type
   - Date range
3. Export logs if needed

### System Settings

1. Click "Settings" in sidebar
2. Configure:
   - **General Settings**:
     - System name
     - Default language
     - Time zone
   - **Security Settings**:
     - Password policy
     - Session timeout
     - Two-factor authentication
   - **Notification Settings**:
     - Email notifications
     - SMS notifications
   - **Backup Settings**:
     - Automatic backup schedule
     - Backup retention period

3. Click "Save Settings"

## Manager Guide

Managers oversee day-to-day operations of their assigned nursery.

### Dashboard Overview

Your dashboard shows:
- Today's attendance summary
- Total children enrolled
- Staff overview
- Pending tasks
- Recent notifications

### Managing Children

#### Register New Child

1. Click "Children" in sidebar
2. Click "Add New Child"
3. Fill in child information:
   - **Personal Details**:
     - First and last name
     - Date of birth
     - Gender
   - **Medical Information**:
     - Allergies
     - Medications
     - Special needs
   - **Emergency Contacts**:
     - Primary contact
     - Secondary contact
     - Authorized pick-up persons
4. Assign to a class/group
5. Click "Register Child"

#### Update Child Information

1. Go to "Children"
2. Search or filter to find the child
3. Click on the child's name
4. Click "Edit"
5. Update information
6. Click "Save Changes"

#### Assign Guardians

1. View child details
2. Click "Manage Guardians"
3. Click "Add Guardian"
4. Search for existing parent or create new
5. Specify relationship
6. Click "Add"

### Managing Supervisors

#### Add Supervisor

1. Click "Staff" in sidebar
2. Click "Add Supervisor"
3. Fill in details:
   - Name and contact info
   - Qualifications
   - Employment details
4. Assign to groups/classes
5. Click "Create"

#### Assign Children to Supervisors

1. Go to "Staff"
2. Select a supervisor
3. Click "Assign Children"
4. Select children from the list
5. Click "Save Assignments"

### Attendance Management

#### View Daily Attendance

1. Click "Attendance" in sidebar
2. Select today's date (default)
3. View status for all children:
   - Present (green)
   - Absent (red)
   - Late (yellow)

#### Manual Attendance Entry

If check-in wasn't recorded:
1. Go to "Attendance"
2. Click "Manual Entry"
3. Select child
4. Enter check-in time
5. Add notes if needed
6. Click "Record"

### Reports

#### Generate Attendance Report

1. Click "Reports"
2. Select "Attendance"
3. Choose:
   - Date range
   - Specific children or all
4. Click "Generate"
5. Export as needed

#### View Child Progress Reports

1. Go to "Reports"
2. Select "Child Progress"
3. Choose child
4. View developmental milestones
5. Add new observations

### Communication

#### Send Notifications to Parents

1. Click "Communications"
2. Click "New Message"
3. Select recipients:
   - All parents
   - Specific class
   - Individual parents
4. Write message
5. Choose delivery method:
   - Email
   - SMS
   - In-app notification
6. Click "Send"

## Supervisor Guide

Supervisors handle daily operations and child care activities.

### Dashboard Overview

Your dashboard shows:
- Children assigned to you today
- Attendance status
- Today's schedule
- Pending tasks
- Announcements

### Daily Attendance

#### Check-in Children

1. Click "Attendance" in sidebar
2. Today's date is selected by default
3. For each arriving child:
   - Click the "Check In" button
   - Record time (auto-fills current time)
   - Add notes if needed (e.g., "Arrived with mother")
4. Click "Save"

#### Check-out Children

1. Go to "Attendance"
2. Find the child
3. Click "Check Out"
4. Record time
5. Note who picked up the child
6. Click "Save"

### Activity Tracking

#### Record Daily Activities

1. Click "Activities"
2. Select your group/class
3. Record activities:
   - Meals and snacks
   - Nap times
   - Educational activities
   - Play time
   - Outdoor time
4. Add photos (optional)
5. Click "Save"

#### Add Observations

Document child development:
1. Go to child's profile
2. Click "Add Observation"
3. Select category:
   - Physical development
   - Social-emotional
   - Language
   - Cognitive
4. Describe observation
5. Add photos/videos if applicable
6. Click "Submit"

### Incident Reporting

#### Report an Incident

If a child is injured or involved in an incident:
1. Click "Incidents"
2. Click "New Incident Report"
3. Fill in details:
   - Child involved
   - Date and time
   - Type of incident
   - Description
   - Action taken
   - Witnesses
4. Attach photos if relevant
5. Click "Submit"

Parents will be automatically notified.

### Communication

#### Message Parents

1. Click "Messages"
2. Click "New Message"
3. Select parent(s)
4. Write message
5. Click "Send"

#### View Messages

1. Go to "Messages"
2. View inbox
3. Click on a message to read
4. Reply if needed

### Reports

#### Submit Daily Reports

1. Click "Reports"
2. Select "Daily Report"
3. Fill in:
   - General observations
   - Highlights
   - Concerns
   - Supplies needed
4. Click "Submit"

Manager will be notified.

## FAQ

### General Questions

**Q: I forgot my password. How do I reset it?**
A: Click "Forgot Password" on the login page, enter your email, and follow the instructions sent to your email.

**Q: Can I access the system from my mobile phone?**
A: Yes, the system is fully responsive and works on all devices including smartphones and tablets.

**Q: How do I update my email address?**
A: Go to Settings > Profile > Contact Information, update your email, and verify it through the confirmation email sent.

### For Parents

**Q: How do I know if my child arrived safely?**
A: You'll receive an automatic notification when your child is checked in. You can also check the dashboard anytime.

**Q: Can I add multiple children?**
A: Yes, all your children will be automatically linked to your account. You can view them all from "My Children".

**Q: How do I report that my child will be absent?**
A: Go to Attendance > Report Absence, select your child and the date(s), provide a reason, and submit.

**Q: Can I download my child's progress reports?**
A: Yes, go to Reports, select your child, open any report, and click the Download button.

### For Managers

**Q: How do I add a new supervisor?**
A: Go to Staff > Add Supervisor, fill in their details, assign them to classes, and create their login credentials.

**Q: Can I export attendance data?**
A: Yes, go to Reports > Attendance, select your criteria, generate the report, and export as CSV or PDF.

**Q: How do I communicate with all parents at once?**
A: Go to Communications > New Message, select "All Parents" as recipients, write your message, and send.

### For Supervisors

**Q: What if I forget to check in a child?**
A: You can manually add attendance entry. Go to Attendance > Manual Entry, select the child, enter the actual time, and save.

**Q: How do I report an emergency?**
A: Use the Incident Report feature immediately. For medical emergencies, call emergency services first, then document in the system.

**Q: Can I see past observations I made about a child?**
A: Yes, go to the child's profile and click "Observations History" to see all past observations.

### Technical Issues

**Q: The page is loading slowly. What should I do?**
A: Try:
- Refresh the page (F5)
- Clear your browser cache
- Check your internet connection
- Try a different browser

**Q: I'm getting an error message. What should I do?**
A:
- Take a screenshot of the error
- Try logging out and back in
- Contact your administrator or IT support
- Include the error message and what you were doing when it occurred

**Q: Can I use the system offline?**
A: No, the system requires an internet connection to function. Some data may be cached for viewing, but you need to be online to make changes.

### Data and Privacy

**Q: Is my data secure?**
A: Yes, the system uses industry-standard encryption and security measures to protect all data.

**Q: Who can see my child's information?**
A: Only authorized staff (assigned supervisors, managers, and administrators) and you as the parent can view your child's information.

**Q: How long is data kept in the system?**
A: Data retention policies are set by your nursery administrator. Contact them for specific information.
